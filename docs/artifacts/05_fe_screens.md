# FlashHook — FE 화면 구성

> React (Vite) + TypeScript / MVP: Webhook Catcher
> 최종 수정: 2026-06-07

---

## 1. 페이지 목록

| #   | 페이지      | 경로                      | 설명                              |
| --- | ----------- | ------------------------- | --------------------------------- |
| 1   | 랜딩 페이지 | `/`                       | 서비스 소개 + 엔드포인트 생성     |
| 2   | 대시보드    | `/dashboard/{endpointId}` | 실시간 로그 모니터링 (핵심)       |

```
│                                              │
│       ⚡ 1초 만에 Webhook URL 생성            │
│       회원가입 없이. 24시간 후 자동 파기.       │
│                                              │
│     ┌─────────────────────────────────┐      │
│     │ Label (선택): [토스 결제테스트  ] │      │
│     └─────────────────────────────────┘      │
│         [ 🚀 Webhook Catcher 만들기 ]         │
│                                              │
├──────────────────────────────────────────────┤
│  📋 이런 분들이 씁니다                         │
│  • BE 개발자: 외부 웹훅 Payload 확인          │

├──────────────────────────────────────────────┤
│  footer: GitHub · 만든이                      │
└──────────────────────────────────────────────┘
```

### 구성 요소

| 요소        | 설명                                                  |
| ----------- | ----------------------------------------------------- |
| 히어로 섹션 | 서비스 한 줄 소개 + CTA                               |
| Label 입력  | optional. placeholder 예시: "토스 결제테스트"         |
| 생성 버튼   | `POST /api/endpoints` → 성공 시 대시보드로 리다이렉트 |
| 사용 사례   | 간단한 타겟 유저별 소개                               |
| Footer      | GitHub 링크, 만든이 정보                              |

### 동작 플로우

```
[생성 버튼 클릭]
  → POST /api/endpoints { "label": "..." }
  → 응답에서 accessToken 추출
  → sessionStorage에 accessToken 저장
  → /dashboard/{endpointId} 로 리다이렉트
```

### 3.1. 상단 영역: 엔드포인트 정보

| 요소            | 설명                                       |
| --------------- | ------------------------------------------ |
| Label           | 엔드포인트 이름 (없으면 미표시)            |
| 만료 카운트다운 | `expiresAt` 기준 실시간 감소 (FE 타이머)   |
| Webhook URL     | 클릭 시 클립보드 복사 + 토스트 알림        |
| 상태 표시줄     | SSE 연결 상태 · 로그 건수/상한 · 용량/상한 |

### 3.2. 좌측: 로그 목록 (실시간)

| 요소             | 설명                                               |
| ---------------- | -------------------------------------------------- |
| HTTP Method 배지 | `POST`=초록, `GET`=파랑, `PUT`=주황, `DELETE`=빨강 |
| bodyPreview      | 앞 300자 텍스트 미리보기                           |
| 메타 정보        | Client IP, Body 크기, 수신 시각                    |
| 실시간 업데이트  | SSE → 새 로그 상단 추가 + 슬라이드인 애니메이션    |
| 클릭             | 해당 로그 상세를 우측 패널에 표시                  |

### 3.3. 우측: 로그 상세 패널

| 요소         | 설명                               |
| ------------ | ---------------------------------- |
| 전체 Headers | key-value 테이블                   |
| 전체 Body    | JSON → syntax highlight + 포맷팅   |
| Query Params | 파싱된 key-value                   |
| 메타 정보    | Method, Client IP, Size, Timestamp |

### 3.4. 하단: 액션 버튼

| 버튼            | 동작                                                                   |
| --------------- | ---------------------------------------------------------------------- |
| 로그 전체 삭제  | `DELETE /api/endpoints/{id}/logs` → 확인 모달 후 실행                  |
| 엔드포인트 삭제 | `DELETE /api/endpoints/{id}` → 확인 모달 후 실행 → 랜딩으로 리다이렉트 |

### 3.5. 상태별 화면

| 상태               | 표시                                                             |
| ------------------ | ---------------------------------------------------------------- |
| 로그 0건 (대기 중) | "📡 웹훅을 기다리는 중..." + URL 복사 유도                       |
| SSE 연결 끊김      | "⚠️ 연결이 끊겼습니다. 재연결 중..." + 자동 재연결               |
| 엔드포인트 만료    | 대시보드 → 만료 안내 페이지로 리다이렉트                         |
| 로그 상한 도달     | 상태 표시줄: "⚠️ 로그 상한 도달 — 오래된 로그가 순환 삭제됩니다" |
| 로그 미선택        | 우측 패널: "← 로그를 선택하면 상세 정보가 표시됩니다"            |

## 5. 주요 FE 컴포넌트

```
src/
├── pages/
│   ├── LandingPage.tsx
│   ├── DashboardPage.tsx
│   └── NotFoundPage.tsx
├── components/
│   ├── Header.tsx              // 공통 헤더 (로고)
│   ├── EndpointInfo.tsx        // 상단 정보 바 (URL, 카운트다운, 상태)
│   ├── CopyButton.tsx          // URL 복사 버튼 + 토스트
│   ├── LogList.tsx             // 좌측 로그 목록 (SSE 실시간)
│   ├── LogItem.tsx             // 개별 로그 항목
│   ├── LogDetail.tsx           // 우측 상세 패널
│   ├── MethodBadge.tsx         // HTTP Method 컬러 배지
│   ├── JsonViewer.tsx          // Body JSON syntax highlight
│   ├── CountdownTimer.tsx      // 만료 카운트다운
│   ├── ConnectionStatus.tsx    // SSE 연결 상태 표시
│   └── ConfirmModal.tsx        // 삭제 확인 모달
├── hooks/
│   ├── useSSE.ts               // SSE 연결 관리 커스텀 훅
│   └── useEndpoint.ts          // 엔드포인트 API 호출 훅
├── utils/
│   ├── api.ts                  // API 클라이언트
│   └── tokenStorage.ts         // sessionStorage 토큰 관리
└── styles/
    └── index.css               // 다크 모드 디자인 시스템
```
