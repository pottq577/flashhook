## 2. 랜딩 페이지 (`/`)

```text
┌──────────────────────────────────────────────┐
│  🔗 FlashHook                                │
├──────────────────────────────────────────────┤
│                                              │
│       ⚡ 1초 만에 Webhook URL 생성            │
│       회원가입 없이. 24시간 후 자동 파기.       │
│                                              │
│     ┌─────────────────────────────────┐      │
│     │ Label (선택): [토스 결제테스트  ] │      │
│     └─────────────────────────────────┘      │
│         [ 🚀 Webhook Catcher 만들기 ]         │
│                                              │
├──────────────────────────────────────────────┤
│  📋 이런 분들이 씁니다                         │
│  • BE 개발자: 외부 웹훅 Payload 확인          │
│  • FE 개발자: Mock API 테스트 (Phase 2)       │
├──────────────────────────────────────────────┤
│  footer: GitHub · 만든이                      │
└──────────────────────────────────────────────┘
```

### 구성 요소

| 요소        | 설명                                                  |
| ----------- | ----------------------------------------------------- |
| 히어로 섹션 | 서비스 한 줄 소개 + CTA                               |
| Label 입력  | optional. placeholder 예시: "토스 결제테스트"         |
| 생성 버튼   | `POST /api/endpoints` → 성공 시 대시보드로 리다이렉트 |
| 사용 사례   | 간단한 타겟 유저별 소개                               |
| Footer      | GitHub 링크, 만든이 정보                              |

### 동작 플로우

```text
[생성 버튼 클릭]
  → POST /api/endpoints { "label": "..." }
  → 응답에서 accessToken 추출
  → sessionStorage에 accessToken 저장
  → /dashboard/{endpointId} 로 리다이렉트
```

### 3.1. 상단 영역: 엔드포인트 정보

| 요소            | 설명                                       |
| --------------- | ------------------------------------------ |
| Label           | 엔드포인트 이름 (없으면 미표시)            |
| 만료 카운트다운 | `expiresAt` 기준 실시간 감소 (FE 타이머)   |
| Webhook URL     | 클릭 시 클립보드 복사 + 토스트 알림        |
| 상태 표시줄     | SSE 연결 상태 · 로그 건수/상한 · 용량/상한 |

### 3.2. 좌측: 로그 목록 (실시간)

| 요소             | 설명                                               |
| ---------------- | -------------------------------------------------- |
| HTTP Method 배지 | `POST`=초록, `GET`=파랑, `PUT`=주황, `DELETE`=빨강 |
| bodyPreview      | 앞 300자 텍스트 미리보기                           |
| 메타 정보        | Client IP, Body 크기, 수신 시각                    |
| 실시간 업데이트  | SSE → 새 로그 상단 추가 + 슬라이드인 애니메이션    |
| 클릭             | 해당 로그 상세를 우측 탭 패널에 표시                  |

### 3.3. 우측: 탭 패널 (로그 상세 / Mock 설정)

**[로그 상세 탭]**
| 요소         | 설명                               |
| ------------ | ---------------------------------- |
| 전체 Headers | key-value 테이블                   |
| 전체 Body    | JSON → syntax highlight + 포맷팅   |
| Query Params | 파싱된 key-value                   |
| 메타 정보    | Method, Client IP, Size, Timestamp |

**[Mock 설정 탭]**
| 요소         | 설명                               |
| ------------ | ---------------------------------- |
| Preset 선택  | K-API (토스, 카카오 등) 템플릿 주입|
| Status Code  | HTTP 상태 코드 설정 (200, 400 등)  |
| Delay (ms)   | 응답 지연 시간 설정 (최대 10000ms) |
| Headers      | 커스텀 응답 헤더 추가 (Key-Value)  |
| Body         | 커스텀 응답 Body 설정 (JSON 등)    |

### 3.4. 하단: 액션 버튼

| 버튼            | 동작                                                                   |
| --------------- | ---------------------------------------------------------------------- |
| 로그 전체 삭제  | `DELETE /api/endpoints/{id}/logs` → 확인 모달 후 실행                  |
| 엔드포인트 삭제 | `DELETE /api/endpoints/{id}` → 확인 모달 후 실행 → 랜딩으로 리다이렉트 |

### 3.5. 상태별 화면

| 상태               | 표시                                                             |
| ------------------ | ---------------------------------------------------------------- |
| 로그 0건 (대기 중) | "📡 웹훅을 기다리는 중..." + URL 복사 유도                       |
| SSE 연결 끊김      | "⚠️ 연결이 끊겼습니다. 재연결 중..." + 자동 재연결               |
| 엔드포인트 만료    | 대시보드 → 만료 안내 페이지로 리다이렉트                         |
| 로그 상한 도달     | 상태 표시줄: "⚠️ 로그 상한 도달 — 오래된 로그가 순환 삭제됩니다" |
| 로그 미선택        | 우측 패널: "← 로그를 선택하면 상세 정보가 표시됩니다"            |

## 5. 주요 FE 컴포넌트 구조 (FSD)

```text
src/
├── app/
│   ├── App.tsx                 // 앱 전역 라우팅
│   └── providers/              // QueryProvider 등 앱 프로바이더
├── pages/
│   ├── landing/ui/             // 랜딩 페이지
│   ├── dashboard/ui/           // 대시보드 페이지 (Split View 및 Tab 상태 관리)
│   └── not-found/ui/           // 404 및 만료 안내 페이지
├── widgets/
│   ├── header/ui/              // 공통 헤더 (로고)
│   ├── endpoint-info/ui/       // 상단 정보 바 (EndpointInfo, ConnectionStatus, CountdownTimer)
│   ├── log-viewer/ui/          // 로그 목록 및 상세 뷰 (LogList, LogItem, LogDetail, JsonViewer)
│   └── mock-config/ui/         // Mock API 응답 설정 패널 (MockConfigPanel)
├── features/
│   └── realtime-logs/          // SSE 실시간 로그 수신 로직 (useRealtimeLogs)
├── entities/
│   ├── endpoint/               // 엔드포인트 도메인 API 및 쿼리
│   └── log/                    // 로그 도메인 모델, 상태 스토어(Zustand), API
└── shared/
    ├── api/                    // API 클라이언트 (fetch 래퍼)
    ├── lib/                    // 커스텀 훅 및 유틸 (useIsMobile 등)
    └── ui/                     // 재사용 공통 컴포넌트 (MethodBadge, Toast, CopyButton, ConfirmModal 등)
```
